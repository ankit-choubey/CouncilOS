# CouncilOS Roadmap 🗺️

This document outlines the roadmap and future milestones for CouncilOS.

## 🚀 Phase 1: Core Architecture & Single-Turn Debate (Q2 2026)
- [ ] Define basic agent abstractions (`Agent`, `Advocate`, `Critic`).
- [ ] Implement initial state space and memory tracking.
- [ ] Build basic debate engine (1 advocate, 1 critic, 1 judge).
- [ ] Create basic evaluation metrics for judges.

## 👥 Phase 2: Multi-Agent Councils & Dynamic Protocols (Q3 2026)
- [ ] Support multi-round debates with turn-taking logic.
- [ ] Implement voting and consensus protocols (e.g., Majority Vote, Elo-based, Synthesis).
- [ ] Integrate external tools (Search, RAG) for agents to cite sources.
- [ ] Add session logging and visualization interface.

## 🧠 Phase 3: Advanced Cognitive Models & Evaluation (Q4 2026)
- [ ] Implement long-term episodic and semantic memory.
- [ ] Create a "Red Teaming" protocol for testing robust alignment and security guardrails.
- [ ] Run benchmark test suites on standard reasoning datasets (MMLU, GSM8K).
- [ ] Support production deployment recipes (Docker, FastAPI wrapper).
