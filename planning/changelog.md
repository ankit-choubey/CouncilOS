# Changelog 📋

All notable changes to the CouncilOS project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-05-19

### Added
- Initial directory structure for CouncilOS framework.
- Root configuration and deployment files (`README.md`, `.gitignore`, `requirements.txt`, `.env`, `setup.py`).
- Planning templates (`roadmap.md`, `architecture.md`, `decisions.md`, `changelog.md`, `research_notes.md`).
- Python package layout in `app/` containing modules for `automation`, `agents`, `protocols`, `memory`, `retrieval`, `judges`, and `utils`.
